About the feature report

It is not written by hand. Each shipment's report is an end-to-end run against that exact installer's payload — the till driven the way a cashier drives it, screenshotted at every step, with what must work and what must be refused counted separately. Both builds pass all 54 checks. If a run fails, the build does not ship.

Installing

The installer needs no admin rights and installs for the current user only. The machine needs nothing beforehand, not even the .NET runtime. Read the runbook first — the lane's settings.json has four fields that must be right before the first sale, and one of them cannot be changed afterwards.
