# Tour recordings

A person reading the tour script, one file a line. The script, with every line numbered, is
`artifacts\showcase\recording-script.html` once the tour has been made (see `..\README.md`).

| Folder | What goes in it |
|---|---|
| `billing-ta\` | The billing tour in Tamil, lines 01 to 17 |
| `billing-en\` | The billing tour in English, lines 01 to 17 |
| `owner-ta\` | The owner's tour in Tamil, lines 01 to 25 |
| `owner-en\` | The owner's tour in English, lines 01 to 25 |

Name each file by its line's number: `01.m4a`, `02.m4a`, and so on. A phone's voice recorder is
fine; `.m4a`, `.mp3`, `.wav`, `.aac` and `.wma` are all read. Leave a second of quiet before and
after each line.
