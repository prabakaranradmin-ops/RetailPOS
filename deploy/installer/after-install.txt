RetailPOS is installed. Three things before the shop can trade.


1. FILL IN THE SETTINGS

   A settings file has been put at:

       %LOCALAPPDATA%\RetailPOS\settings.json

   It is the Tamil pilot template: prefix RM, single till, 80mm paper. Open it in
   Notepad and replace every FILL IN, then delete the two _comment lines at the top.

   Take the shop name, GSTIN and FSSAI number from the shop's own certificates -
   not from an old printed bill. One wrong character prints on every invoice the
   shop ever issues, and nothing in the software can catch it.

   Put the printer name in exactly as Windows shows it under Printers & Scanners.

   Save it as UTF-8. In Notepad: File > Save As > Encoding > UTF-8 with BOM.
   Saving it any other way turns a Tamil shop name into nonsense on every bill.

   The till will not open until this is done. It names any field you missed.

   (If this lane was already trading, your existing settings were left alone.)


2. CHECK THE HARDWARE

   Open the till, press Ctrl+D for the owner's screen, then Ctrl+4 for
   Hardware. There is a button for the printer, the drawer, the scanner and
   the scale, and one that lists the serial ports.

   Press "Draw it as the printer will" before printing anything. If any Tamil
   shows as ? or as strange Latin letters, stop - the lane cannot draw it, and
   the screen says why.

   The same checks from "RetailPOS commands", if you prefer typing:

       pos.exe receipt-preview --png preview.png
       pos.exe test-hardware

   HARDWARE_SIGNOFF.html in the install folder is the sheet to work through.
   Double-click it, then print it.


3. LOAD THE CATALOGUE

   Open the till, press Ctrl+D for the owner's screen, then Ctrl+3 for
   Catalogue. Pick the file and press "Check the file" before importing.

   The check writes nothing and lists every problem by line, so the fix happens
   in the spreadsheet. Import stays greyed out until the check is clean, and if
   it reports problems the catalogue is exactly as it was.

   Save the sheet from Excel as CSV UTF-8. catalog_template.csv shows the
   format, and CATALOGUE_FORMAT.md lists every column.

   The same thing from "RetailPOS commands", if you prefer typing:

       pos.exe import-items --file catalogue.csv --dry-run
       pos.exe import-items --file catalogue.csv


Then open the till from the desktop shortcut.

PILOT_RUNBOOK.html is the day-to-day guide: opening, the keys, closing the day,
and what to do when something goes wrong. It is on the Start menu as "Operator
runbook".

Uninstalling removes the program and leaves the lane's database, settings and
backups alone. They are the shop's books.
